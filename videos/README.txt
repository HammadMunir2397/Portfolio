📁 VIDEOS FOLDER
================

Place your game demo videos here!

Supported formats:
- .mp4 (Recommended - works everywhere)
- .webm
- .ogg

Example structure:
videos/
├── WebGame.mp4
├── game-demo-2.mp4
└── game-demo-3.mp4

Then update script.js with the path:
videoUrl: 'videos/WebGame.mp4',

Tips:
- Keep files under 50MB for faster loading
- Use 1080p or 720p resolution
- Keep videos short (30-90 seconds)
- Name files without spaces (use hyphens or camelCase)

Good names: ✅
- my-game-demo.mp4
- GameDemo.mp4
- cyera-endless.mp4

Bad names: ❌
- My Game Demo.mp4
- game demo (1).mp4

For more help, see VIDEO-SETUP-GUIDE.md
